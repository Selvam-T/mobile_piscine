    - Used a 5-column button grid with GridView.builder.

ex03:

    - built on ex02, made operational
    - "AC" clear whole expression, show 0
    - "C" clear last character, if none show 0
            - not clear last number. Ex: 10 + 20 --> clear 0, not 20
    - "." a) multiple . is invalid, b) correct format example 0.6
    - "=" :
        a) If the next key after = is an operator, treat the result as the new starting value.
            663 + 5 =
            Result: 668
            Next key: +

            Expression: 668+
            Result: 668

        b) If the next key after = is an operand/number, a normal calculator starts a new expression.
            663 + 5 =
            Result: 668
            Next key: 9

            Expression: 9
            Result: 668
    - Division by 0, return Error ✅

    - "-" as subtractor vs unary negative sign ✅
        - if preceded by operator, then "-" is unary sign
            5 - 3 = 2
        - if preceded by operand, then "-" is operator
            5 - - 3 = 8
    
    - Handle very large numbers without crash. ✅
        Instead of overflowing, rounding badly, or turning into misleading output,
        show 'Too Large'

        static const double _maxResultMagnitude = 1000000000000;
