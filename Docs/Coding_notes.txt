Additional notes:
    HourlyForecast class: 
        A simple immutable data model class used to hold hourly weather information 
        (hour, temperature, wind speed, and description).
    Class properties: 
        Declaring fields provides type safety, improves code clarity, 
        enables better IDE support, and makes the object immutable using final.
    CitySuggestion class: 
        Uses a factory constructor named fromJson to create objects from JSON maps. 
        The admin1 key from the API is mapped to the region property for better readability.
    @override annotation: 
        Used in shouldRepaint() to indicate the method is overriding the parent CustomPainter class. 
        It determines whether the chart should be redrawn based on data changes for performance optimization.

- Google and GitHub now use Firebase popup auth:
    - FirebaseAuth.instance.signInWithPopup(...)
    - Firebase Auth persists login state
    - This stream emits User? user --> user != null: someone is signed in

    - So when you log in again, browser active account is silently reused
